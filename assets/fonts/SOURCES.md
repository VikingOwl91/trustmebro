# Local font assets

These files were copied from the npm packages below and are served by the static build. The source packages declare the SIL Open Font License 1.1; their license texts are kept beside the font files.

- `@fontsource/dm-mono` 5.3.0: Latin normal weights 400 and 500.
- `@fontsource/space-grotesk` 5.3.0: Latin normal weights 400, 500, 600 and 700.

The generated page embeds these local WOFF2 files in its bundled stylesheet. It does not request Google Fonts.
