# TRUSTMEBRO

Privacy-first, browser-local scam and phishing email analyzer.

## Current state

The v0.1/v0.2 prototype analyzes `.eml` files locally, applies deterministic explainable rules, and exports a reproducible JSON report. No raw email, message body, attachments, telemetry, or external reputation requests leave the browser.

The hosted prototype is available at [trustmebro.owlibou-5462.chatgpt.site](https://trustmebro.owlibou-5462.chatgpt.site).
